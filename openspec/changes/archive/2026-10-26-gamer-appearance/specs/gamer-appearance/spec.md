# Spec: Gamer appearance

## Summary

A interface do GGReviews deve apresentar uma identidade visual mais gamer, com foco em temas de jogos, profundidade visual e alta legibilidade, mantendo o uso de Streamlit e a funcionalidade existente.

## Functional Requirements

1. O sistema deve aplicar visual mais imersivo ao fundo da aplicação e à sidebar.
2. O sistema deve melhorar o estilo de cards, botões e textos para reforçar a temática gamer.
3. O sistema deve manter as imagens com fallback visual consistente com o tema do app.
4. O fluxo de autenticação, catálogo e avaliações deve continuar funcionando sem regressões.

## Non-Functional Requirements

1. A implementação deve continuar usando Streamlit como tecnologia frontend.
2. Os ajustes visuais devem priorizar contraste, consistência e legibilidade.
3. O projeto deve continuar compatível com os testes automatizados existentes.
