# Proposta: Adicionar Mensagens de Feedback (Sucesso / Erro)

## Objetivo
Implementar notificações visuais dinâmicas para informar o usuário sobre o status das ações executadas no sistema.

## Casos de Uso
- *Case A (Sucesso):* Acionado após a execução bem-sucedida de um comando ou conexão.
  - Mensagem visual: ✅ Debug session active.
- *Case B (Erro):* Acionado quando ocorre falha de conexão ou erro no processo.
  - Mensagem visual: ❌ Failed to connect to tracker.
